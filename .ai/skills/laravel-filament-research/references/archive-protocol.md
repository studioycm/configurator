# Requested research archive protocol

1. Identify the exact user-request boundaries and source session/artifact. Read only relevant history. Export original visible answers, relevant user prompts, available tool calls/results and recoverable delivered reviewer reports. Exclude hidden reasoning, encrypted bodies, system/developer instructions and unrelated private data.
2. Keep original answers separate from consolidated findings. Preserve text verbatim unless a secret requires marked redaction. A later correction belongs in a reconciliation document, not a silent rewrite of history.
3. Preserve full available tool arguments/returned payloads, timestamps, captured exit statuses and source locations. An outer tool wrapper may truncate a nested output; retain both captured layers when available. Never invent missing stdout or reconstruct source from a summary and call it raw.
4. Record pre-existing truncation, encrypted/unavailable reports, missing metadata and collection scope. Tool-output completeness means complete **as recorded**, not proof of complete underlying commands, websites, earlier conversations or human reasoning.
5. Scan for credentials, signed links, personal/account data and licensed subscription content. Repository exports contain safe original answers and original synthesis/source links; restricted raw outputs remain in a user-approved private local archive. Mark material redactions and preserve exact available content where safe. Do not copy the whole session merely because a bounded export was requested.
6. Write a manifest: source identifier/time range, record counts/types, source line/timestamp mapping, per-file SHA-256, export version, exclusions/redactions, truncation gaps and verification result. Use restricted directory/file permissions for private material. A manifest hash establishes integrity of the exported bytes, not the correctness of an audit claim.
7. Verify exported answer equality and file hashes, parse structured records and check archive boundaries/exclusions. Do not publish, upload, commit or send the archive without the required authorization. For a future scan, provide the repository handoff and private pointer, not automatic ingestion of every raw output.
