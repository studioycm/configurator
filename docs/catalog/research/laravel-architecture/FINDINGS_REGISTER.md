## Boundaries to protect

Both audits preserve the authoritative `SaveConfiguratorDefinition` writer; engine/compiler/loader separation; engine DTO contracts; signed tested-change guards; catalog revisions/snapshots; canonical/inclusion usage query services; specialized string replacement; exact Product editor keys/structured values. Audit 2 additionally preserves `ConfiguratorRuleDraft`, coherent pure `ConfiguratorPreviewNotes`, legitimate class-based ProductConfigurator/preview inheritance, tag components already delegating to Actions, `tableFilters` paths/FilaCheck exception and browser-local preferences/client snapshot computation.

No finding grants permission to delete classes/tests, change dependencies or implement a Product-data behavior change. The later detailed implementation plan should be written only after the refreshed recommendation set is reviewed.
